# Migration: React + Vite SPA to Astro 7

Status log for the rework of jcernuda.com. Written before any code changed (Step 0), then extended after each step.

## Why

The live site served an empty `<div id="root">` and fetched its content from `/content/*.md` after React loaded. Every deep URL returned HTTP 404 (GitHub Pages 404 redirect trick), so Google indexed nothing. The rework produces prerendered HTML for every route with real metadata, keeps every URL, and moves content into typed collections.

## Frontmatter fields in use

Publications: `title`, `authors` (comma-separated string), `type` (Conference, Workshop, Poster), `venue` (e.g. `ICPP'24`), `year` (number), `featured` (bool, true only for hstream), `tags` (array), `description` (hstream only), `links.pdf` (14), `links.code` (11), `links.poster` (3), `citation` (BibTeX literal block).

Projects: `title`, `description`, `year` (number), `category`, `featured` (iowarp), `status` ("On-going"), `tags`, `links.website`, `links.code`, `image`.

Blog: `title`, `summary`, `date` (strings such as "Aug 15, 2023", "Sept 28, 2023"), `category`, `readTime`, `popular`, `tags`.

home: `hero.{title, subtitle (markdown), status, image, social_links[{name, icon, url}]}`, `stats[{label, value}]`, `featured_projects` (filenames), `featured_publication` (slug), `selected_publications` (filenames).

cv: `profile.{name, title, email, website, location, image}`, `summary`, `education[{degree, school, year, details[]}]`, `experience[{role, company, year, details[]}]`, `publications[{title, authors, venue}]`, `skills.{languages, tools, spoken}`, `awards[]`.

news: `title`, `news[{date ("Mon YYYY"), title, description, link}]`.

footer: `contact.{title, text, button_text, email}`, `copyright`, `social_links[]`.

List pages: `header.{title, subtitle}` plus `folder`; blog adds `header.image`, `header.image_dark`, `posts[]`, `sidebar.profile.{name, role, bio, image}`.

## Known defects before migration

- Deep URLs 404 to crawlers; HTML shell has no per-page title, description, canonical, or Open Graph tags.
- Home Featured Research block never rendered (broken reference).
- Home cite modal passed the wrong prop and showed an empty citation.
- Projects year filter compared string to number and matched nothing; every project GitHub icon linked to the profile instead of `links.code`.
- CV page subtitle was template text about computer vision; CV website link was `#`.
- Layout rendered nothing until `footer.md` loaded.
- Dark mode applied after hydration, so light-mode users saw a dark flash.
