Agent Error Simulator is a controllable fault-injection benchmark for agent-induced errors in multi-agent workflows, built around an iterative tool-calling computation that scales across agents. It injects logic, formatting, and tool-call errors at chosen times and roles so that recovery mechanisms can be measured despite stochastic agent behavior.
